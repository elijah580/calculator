# Calculator

## Name

Elijah David

A simple scientific calculator built with HTML, CSS, and vanilla JavaScript. It runs entirely in your browser and requires no build step or dependencies.

## Features

- Basic arithmetic: addition, subtraction, multiplication, and division
- Parentheses and decimal numbers
- Sine, cosine, and tangent, using degrees
- Square roots
- Clear and backspace controls
- Keyboard input for numbers, arithmetic operators, parentheses, Enter/`=` to calculate, Backspace to delete, and Escape to clear
- Automatic closing of unclosed parentheses when calculating

## Run locally

1. Clone or download this repository.
2. Open `index.html` in a web browser.

You can also serve the project with any static web server. There is no install or build step.

## Use

Click the calculator buttons or use the supported keyboard keys. For example, enter `2 + 3` and press `=` or Enter. Click **ac** or press Escape to clear, and click **⌫** or press Backspace to delete the last character.
